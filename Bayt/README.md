# iOS 底层知识播客应用

这是一个专门为你设计的 iOS 播客应用，能够将你的 iOS 底层知识体系转换为音频，方便你在上下班途中复习和巩固知识。

## 🎯 功能特点

- **📚 完整知识覆盖**: 支持9大知识模块，包括语言基础、系统框架、多线程内存、性能优化等
- **🎙️ 文本转语音**: 利用 iOS 原生 AVFoundation 框架实现高质量中文语音朗读
- **🎵 播放控制**: 支持播放、暂停、快进、快退、语速调节等功能
- **🔍 智能搜索**: 支持按标题、内容、分类、优先级等多维度筛选
- **⏯️ 后台播放**: 支持后台继续播放，不影响使用其他应用
- **📱 精美界面**: SwiftUI 构建，提供现代化用户体验

## 🚀 如何使用

### 1. 在 Xcode 中打开项目

```bash
cd /Users/fengcaifan/Documents/fcfgithub/iOSLearningSet/Bayt
open PodcastApp.xcodeproj
```

### 2. 选择目标设备

- 选择 iPhone 模拟器或真机
- 推荐使用 iPhone 12 或更新机型以获得最佳体验

### 3. 运行应用

- 点击 Xcode 的运行按钮 (⌘R)
- 首次运行需要授予音频播放权限

### 4. 开始学习

1. **浏览内容**: 在主界面浏览所有可用的播客内容
2. **搜索筛选**: 使用搜索框和筛选器找到你想学习的内容
3. **点击播放**: 点击任意播客单集开始播放
4. **控制播放**: 在详细界面控制播放进度和语速
5. **后台收听**: 切换到其他应用，音频会继续播放

## 🎛️ 主要功能说明

### 播放控制

- **播放/暂停**: 点击大圆按钮控制播放状态
- **快进/快退**: 点击左右箭头按钮跳转播放位置
- **语速调节**: 在详细界面选择 0.3x - 1.0x 的播放速度

### 内容组织

播客内容按以下结构组织：

- **01-语言基础**: Runtime、RunLoop、Block、KVC/KVO 等
- **02-系统框架**: UIKit、CoreAnimation、SwiftUI 等
- **03-多线程与内存**: 内存管理、多线程编程、锁机制
- **04-性能优化**: 启动优化、卡顿优化、内存优化等
- **05-网络与安全**: HTTP/HTTPS、TCP/UDP、安全机制
- **06-架构与设计**: 设计模式、架构模式、组件化
- **07-工程化**: 编译原理、CI/CD、APM 监控
- **08-系统设计题**: 常见系统设计问题
- **09-面试复盘**: 高频面试题和经验总结

### 优先级说明

- **P0**: 必须掌握，面试高频题
- **P1**: 重要内容，资深岗位常考
- **P2**: 加分项，有则更好
