# iOS 底层知识播客应用 - 快速使用指南

## 🎯 应用概述

这个应用将你丰富的 iOS 底层知识体系转换为了播客形式，让你能够在上下班途中、健身时、做家务时轻松学习 iOS 深层技术知识。

## 🚀 快速开始

### 第一步：打开项目

1. 打开终端，导航到 Bayt 目录：
```bash
cd /Users/fengcaifan/Documents/fcfgithub/iOSLearningSet/Bayt
```

2. 在 Xcode 中打开项目：
```bash
open PodcastApp.xcodeproj
```

### 第二步：运行应用

1. 在 Xcode 中选择目标设备（推荐 iPhone 12 及以上）
2. 点击左上角的运行按钮（或按 ⌘R）
3. 等待应用编译完成并在模拟器/设备上启动

### 第三步：开始学习

1. **浏览内容**：主界面显示所有可用的播客内容
2. **搜索筛选**：使用顶部搜索框和筛选器找到感兴趣的内容
3. **点击播放**：点击任意播客单集开始播放
4. **控制播放**：
   - 大圆按钮：播放/暂停
   - 左右箭头：快退/快进
   - 语速选择：调节朗读速度（0.3x - 1.0x）

## 📱 常见问题

### Q: 为什么有些内容无法播放？
A: 请确保对应的 Markdown 文件存在于指定路径，并且文件格式正确。

### Q: 如何获得更好的语音效果？
A: 建议在 iOS 设置中调整语音选项，选择高质量的中文语音包。

### Q: 可以调整播放速度吗？
A: 可以的，在详细播放界面有 0.3x 到 1.0x 的语速选项。

### Q: 支持离线收听吗？
A: 当前版本需要联网加载文件内容，后续版本会添加离线功能。
